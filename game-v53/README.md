# ELENYA — Direction artistique V53

Direction : fantasy 2.5D peinte, semi-réaliste et mature.

- `sprites/` : neuf personnages détourés sur fond transparent.
- `backgrounds/` : quatorze décors 16:9 optimisés en WebP.
- `interactions/` : références de poses narratives pour les duos.

Les sprites sont prévus pour occuper environ 60 % de la hauteur du jeu. Les décors gardent une zone centrale calme afin de préserver la lisibilité des personnages et du texte.
